# WORM GPT — Ultra Cyber Science

A static, local-first cyber science interface. No backend and no external AI API are required.

## Files
- `index.html` — application shell
- `style.css` — complete responsive cyber/HUD design
- `app.js` — local chat engine, math, physics, 3D-style canvas visualizer, terminal emulator, settings and persistence

## Run
Open `index.html` in a modern browser, or upload the whole folder to GitHub Pages. Keep all three files in the same directory.

The project intentionally uses relative asset paths:
- `./style.css`
- `./app.js`

## Notes
The AI is a local response/simulation engine, not a remote model. The terminal is a safe UI emulator and does not execute system commands. Physics and 3D modules are educational visual simulations.
